# 🌌 Waves — MITAOE Science Organization Website

A visually immersive, modern React.js website built for the **WAVES** club at **MIT Academy of Engineering**, showcasing the organization’s vision, events, and outreach. The site features animated backgrounds, responsive design, and smooth navigation to provide a stunning user experience.


## 🛠️ Tech Stack

- **Frontend:** React.js, Tailwind CSS
- **Routing:** React Router
- **Animations & Media:** MP4 video background, custom canvas animation
- **Icons:** SVG inline icons

## 🔧 Setup Instructions

```bash
# 1. Clone the repository
git clone https://github.com/KingShivamX/waves-mitaoe.git
cd waves-mitaoe

# 2. Install dependencies
npm install

# 3. Run the development server
npm run dev
```
